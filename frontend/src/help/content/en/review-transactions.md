Assign categories to transactions so expenses appear in the appropriate budgets.

## Review transactions

1. If you see a notice about transactions without a category, select **Review transactions**.

[![Transaction list with the Review transactions button highlighted](/marketing/screenshots/en/help-review-start-light.png)](/marketing/screenshots/en/help-review-start-light.png)

2. Open a transaction from the filtered list.

[![An uncategorized transaction in the filtered list](/marketing/screenshots/en/help-review-list-light.png)](/marketing/screenshots/en/help-review-list-light.png)

3. Select **Assign category**.

[![Transaction details with Assign category highlighted](/marketing/screenshots/en/help-review-assign-light.png)](/marketing/screenshots/en/help-review-assign-light.png)

4. Choose a category and select **Save**. The expense category determines where it appears in [budgets](/help/en/budgets/).

[![Selected category and highlighted Save button](/marketing/screenshots/en/help-review-save-light.png)](/marketing/screenshots/en/help-review-save-light.png)
