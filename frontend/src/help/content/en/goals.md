A goal helps you plan your savings and track how much you have set aside.

## Create a goal

1. Open **Goals** and choose **New goal**.

[![Goal list with the New goal button highlighted](/marketing/screenshots/en/help-goal-create-light.png)](/marketing/screenshots/en/help-goal-create-light.png)

2. Enter a name, target amount and the amount you have already saved.

[![Create goal form](/marketing/screenshots/en/help-goal-form-light.png)](/marketing/screenshots/en/help-goal-form-light.png)
3. Set a target date and choose whether to start saving this month. You will see how much you need to save each month.
4. Select **Create goal**.

## Record a deposit or withdrawal

1. Open a goal from the list.
2. Select **Add savings** to record a deposit, or **Withdraw money** to record a withdrawal.

[![Goal details with the Add savings button highlighted](/marketing/screenshots/en/help-goal-deposit-light.png)](/marketing/screenshots/en/help-goal-deposit-light.png)

3. Enter the amount and date, add an optional note, then select **Save**.

[![Form for recording a goal deposit](/marketing/screenshots/en/help-goal-deposit-form-light.png)](/marketing/screenshots/en/help-goal-deposit-form-light.png)

You can edit or delete deposits and withdrawals in the goal history. An amount in the [monthly plan](/help/en/monthly-plan/) does not create a deposit; record it separately on the goal page.
