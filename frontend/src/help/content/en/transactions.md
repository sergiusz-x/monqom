Transactions let you record expenses and income and find them later.

## Add a transaction

1. Select **Add transaction** in the app.

[![Add transaction button highlighted](/marketing/screenshots/en/help-transaction-add-light.png)](/marketing/screenshots/en/help-transaction-add-light.png)

2. Choose **Expense** or **Income**, enter the amount and description, and select a category.
3. Check the date and account or wallet under **Transaction details**. You can also add a note.
4. Select **Save transaction**.

[![Form for adding a transaction](/marketing/screenshots/en/help-transaction-form-light.png)](/marketing/screenshots/en/help-transaction-form-light.png)

## Find or change a transaction

Open **Transactions** to search descriptions, sort the list, or filter by dates, category, account, type and origin.

[![Search field on the transaction list](/marketing/screenshots/en/help-transaction-search-light.png)](/marketing/screenshots/en/help-transaction-search-light.png)

Open a transaction to view its details, edit it or delete it. Deleting a transaction cannot be undone.

Learn how to [review uncategorized transactions](/help/en/review-transactions/).
